# First release delivery plan

[Milestone](https://github.com/learn-ukrainian/ukrainian-llm-eval/milestone/1) · [Epic #1](https://github.com/learn-ukrainian/ukrainian-llm-eval/issues/1)

## Outcome

An independently installable Ukrainian-only evaluator and a public, evidence-backed experiment using explicitly selected hosted/subscription model routes. The code can accept other researchers' authorized models without obligating this project to fund them.

## Queue and completion

- #2: governance, security, CI and contributor/release practices.
- #3: standalone engine, immutable evidence and resumable scheduling.
- #4: independently audited ZNO/NMT language, ULP (347 expert proficiency questions) and UA-GEC correction integration.
- #5: exact model/effort inventory and verified isolated provider adapters.
- #6: three-repeat evaluation, analysis and durable evidence.
- #7: public release, clean-install proof and community usefulness assessment.
- #8: reconcile the organization Project board and access.

Each issue owns its acceptance evidence. The loop is issue → worktree → implementation/documentation → tests/behavior proof → independent exact-head review → CI → merge → cleanup → epic reconciliation. Failure returns to repair and renewed validation, or an explicit blocked issue; it never lowers acceptance.

## Experiment contract

Three fresh runs per eligible model/effort/condition. Closed-book has no external tools. Sources-assisted permits only validated reference tools; unsupported MCP routes receive an explicit capability exclusion while remaining eligible for closed-book runs. Disclose exact model/provider/harness, requested and observed effort, prompt/data/configuration hashes, source denominators, grading policy, tool use, usage, timing and failures.

Sources remains an optional live service. Snapshots, backups and corpus publication are deferred to a separate project. Preserve tool evidence and available identity metadata, but do not claim the live corpus is frozen. ULP questions and grading keys must remain outside candidate retrieval. Check possible overlap between benchmark content and references.

Dataset preparation, canaries and development tuning stay separate from scored execution. Pin sources and validate licenses and presentation before declaring a scored dataset. Use official exam scoring and established GEC scoring with independent reference checks. Report per-suite results and appropriate paired uncertainty; repeated matching subparts are not independent questions.

## Release boundaries

No other subjects, no invented human review, no CEFR certification, no general-fluency claim. Unsupported settings are explicit failures/exclusions, never hidden fallbacks. Source/corpus rights govern redistribution separately from the MIT code license. Preserve raw evidence outside Git and publish sanitized reports/manifests with archive hashes.

The public announcement is prepared only after evidence demonstrates usefulness; sending it is a separate maintainer action.
